# Multimedia Player

A personalized multimedia player featuring audio, video, captions, and a transcript, built with HTML as part of the freeCodeCamp Responsive Web Design curriculum.

## Overview

This project is a simple multimedia player featuring an audio track, an educational JavaScript video with English captions, and a transcript of the video.

## Features

- Audio track with playback controls
- Educational JavaScript video
- English captions using the `<track>` element
- Video transcript
- Semantic HTML structure
- Accessible media labels using `aria-label`

## Technologies Used

- HTML5

## What I Learned

Through this project, I practiced:

- Embedding audio with the `<audio>` element
- Embedding video with the `<video>` element
- Using `<source>` to specify media files
- Adding captions with the `<track>` element
- Using `controls` and `aria-label` for media accessibility
- Structuring content with semantic HTML sections
